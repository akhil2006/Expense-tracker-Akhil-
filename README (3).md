# AI-Assisted Expense Tracker

Program 05 · AI Assisted Software Development Lab (BASDLI507)

A web application for tracking expenses. Add expenses, manage categories, view monthly analytics and export to CSV. Data is saved in your browser (localStorage).

## Files
- `index.html`: the web page
- `app.js`: the application code
- `style.css`: styling

## Deploy on Vercel
1. Upload all files to a GitHub repository.
2. On vercel.com: Add New > Project, import the repository.
3. Framework Preset: **Other**. Leave build command and output directory empty.
4. Deploy.
